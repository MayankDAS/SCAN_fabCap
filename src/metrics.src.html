Feedback score

Daily score from 0 to 100. It blends engagement, task success and low friction.
Score = 0.4 × Engagement + 0.4 × Task success + 0.2 × Low friction
Weights sum to 1, so the score stays on a 0 to 100 scale. One more point of engagement or task success adds 0.4 to the score; one more point of low friction adds 0.2. If a component has no data for a day, the other weights are rescaled.

What drives the score

Each component on the same 0 to 100 scale.
